A bespoke, high-performance multipurpose WordPress theme built by ChrisXCreative.

== Description ==

ChrisXCreative is a fast, modern, fully responsive multipurpose WordPress theme
designed for agencies, studios and businesses. It ships with a built-in
Portfolio, Services, Testimonials and Team system, a native AJAX contact form,
one-click demo content, deep Customizer controls, dark mode, and a set of
Gutenberg block patterns — with no page-builder plugin required.

Inspired by the layout conventions of premium multipurpose themes such as
Impreza and The7, rebuilt from scratch as a lightweight, dependency-free
codebase for easy long-term maintenance.

== Getting Started ==

1. Activate the theme.
2. Go to Appearance > Theme Setup and click "Install Demo Content" to
   populate your site with sample pages, portfolio projects, services,
   testimonials, team members and blog posts.
3. Go to Appearance > Customize to add your logo, brand colours, header,
   footer and homepage content.
4. Manage Portfolio, Services, Testimonials and Team from their own menu
   items in the WordPress dashboard sidebar.

== Features ==

* One-click demo content installer (Appearance > Theme Setup)
* Portfolio, Services, Testimonials and Team custom post types
* Native AJAX contact form (no Contact Form 7 required) with honeypot spam protection
* Deep Customizer: colours, header, footer, homepage hero/CTA text, social links
* Light & dark mode with a header toggle, remembered per visitor
* Sticky header, off-canvas mobile menu, full-screen search overlay
* Seven bundled Gutenberg block patterns (hero, CTA, services, pricing, FAQ, stats, contact)
* theme.json colour palette, gradients and typography presets for the block editor
* Three bundled widgets: Social Icons, Contact Info, Recent Portfolio
* WooCommerce compatible out of the box
* Built for speed: no jQuery dependency, deferred scripts, disabled emoji/heartbeat bloat, lazy-loaded images
* Fully responsive across desktop, tablet and mobile
* Accessible: skip links, visible focus states, semantic landmarks, reduced-motion support
* Translation-ready
